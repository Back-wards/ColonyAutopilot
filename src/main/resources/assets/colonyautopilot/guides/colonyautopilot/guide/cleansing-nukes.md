# Cleansing Nukes

The craftable counter-weapons. The two nukes are renamed player-heads — they
never appear in JEI, so their recipes live here. **To use a nuke: drop it on the
ground (default Q) and back away; it arms itself in about a minute.** The Cryo
Grenade is a normal item (it is in JEI, under Spore Inquisition) and is
**thrown** with right-click.

## SZC — the Ice Nuke

The **only** weapon that meaningfully cuts world corruption: about **−19%** per
use (corruption otherwise only ever ratchets upward). It freezes every fungus
creature within ~500 blocks solid, clears fungal blocks across the same range,
and restores the land to snowy taiga.

**Note:** the world-restore is enormous — the game can stall for several minutes
while it works. Let it finish.

## SOLAR PUNCH — the Fire Nuke

A big cleansing blast (a flesh-bomb plus a nuke entity); trims corruption
slightly (~1%).

## Cryo Grenade — the old Ice Bomb

**Right-click to throw it.** It instantly freezes infected blocks and mobs in a
~50×50 area around where it lands. No corruption
change — a tactical tool for breaking a push against the walls, or for freezing
a mound before you kill it (see [the bestiary](bestiary.md) for why that
matters).
